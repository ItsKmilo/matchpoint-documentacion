01 / CÓDIGO FUENTE DEL APLICATIVO

MatchPoint en Python

Aplicación web con Python 3, Flask 3 (Jinja2 y Werkzeug) y SQLite. Implementa las 20 historias del producto: Sprint 1 (HU001 a HU010) y Sprint 2 (HU011 a HU020) y tiene 114 pruebas automáticas, una por cada paso de los criterios de aceptación.

Ver código en GitHub ↗ Descargar ZIP ↧
  • README: cómo ejecutarlo y usuarios de prueba.
  • services.py: reglas de negocio de cada HU.
  • tests/: un archivo de pruebas por HU.
  • schema.sql: modelo de datos y sus restricciones.
CÓMO EJECUTARLO 
cd matchpoint-app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py --demo
# abrir http://127.0.0.1:5000
# admin / admin123 · laura.gomez / demo123

python -m unittest discover -s tests -t . -v

03 / RETROSPECTIVA

Herramienta: tablero Velero

La retrospectiva del Sprint 2 se hace con la técnica Velero (sailboat) en un tablero en línea del propio sitio: viento (lo que impulsó), anclas (lo que frenó), rocas (riesgos) e isla (la meta). Al final el equipo acuerda acciones con responsable.
