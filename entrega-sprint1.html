01 / CÓDIGO FUENTE DEL APLICATIVO

MatchPoint en Python

Aplicación web con Python 3, Flask 3 (Jinja2 y Werkzeug) y SQLite. Implementa las 10 historias del Sprint 1 (HU001 a HU010) y tiene 59 pruebas automáticas, una por cada paso de los criterios de aceptación.

Ver código en GitHub ↗ Descargar ZIP ↧
  • README: cómo ejecutarlo y usuarios de prueba.
  • services.py: reglas de negocio de cada HU.
  • tests/: un archivo de pruebas por HU.
  • schema.sql: modelo de datos y sus restricciones.
CÓMO EJECUTARLO 
cd matchpoint-app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py --demo
# abrir http://127.0.0.1:5000
# admin / admin123 · laura.gomez / demo123

python -m unittest discover -s tests -t . -v
